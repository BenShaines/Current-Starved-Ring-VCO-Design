# Current-Starved Ring VCO (RFIC)
Designed, optimized, and simulated a three-stage Current-Starved Ring VCO in CMOS using Cadence Virtuoso.

## Key Points
- Frequency tuning via control voltage
- Achieved an oscillation frequency of approximately 4 GHz
- Removed the PMOS current-limiting transistors to improve the maximum operating frequency
- Transient analysis and oscillation behavior
- PSS and harmonic analysis
- Phase-noise and jitter simulations
